# Manual installation

The recommended method is **Install-Windows.cmd**. It installs in a shared Windows-user folder for the targeted Illustrator versions.

For manual copying, follow [section 2 of the illustrated README](README.md#2-manual-folder-copy--optional-alternative), then run repair last.

Copy the complete **com.ashad.guidelayout** folder into:

```text
%APPDATA%\Adobe\CEP\extensions
```

Do not use the Illustrator 2026 application-specific folder when you need the same panel in 2020 or 2025. See [version compatibility](COMPATIBILITY.md).
