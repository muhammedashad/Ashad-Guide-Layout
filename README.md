# Ashad Guide Layout

**Free margin and grid extension for Adobe Illustrator on Windows.**

Create artboard margins, columns and rows from a dockable panel. Adjust spacing, preview your layout, then create guides.

**Version 3.0.2 · Windows · Illustrator 2026 (30.0–30.9)**

## Install — recommended method

1. **Close Illustrator.** Save your work first.
2. **Extract the ZIP.** Right-click the downloaded file → **Extract All** → **Extract**.
3. **Open the extracted folder.** Double-click **Install-Windows.cmd**. Keep the other files and folders beside it.
4. **Confirm installation.** Read the message, type **YES**, then press **Enter**. Wait for **Installed**.
5. **Open Illustrator.** Choose **Window → Extensions → Ashad Guide Layout**.

You can drag the panel tab beside your other Illustrator panels to dock it.

**Installation setting:** This is an unsigned extension. Typing **YES** also enables unsigned CEP 12 panels for your Windows account, including other unsigned panels. The installer records the previous setting for optional restoration when uninstalling. Administrator access is normally unnecessary.

## Create your first layout

1. Open a document with an artboard.
2. Choose a preset, the target artboard(s), and your units.
3. Set the margins. Check **Link all sides** for equal margins.
4. Enable columns or rows if needed, then set their count and gutter spacing. Leave Width or Height blank for automatic sizing.
5. Check **Preview** to see the layout. Click **Create guides** when ready.

Turn **Preview** off before saving or closing your document. Choose **Editable lines** if you want coloured lines that appear in exports; native guide colours follow Illustrator Preferences.

## Need help?

| Problem | Fix |
| --- | --- |
| The panel is blank | Close Illustrator. In the extracted package, run **Repair-Blank-Panel.cmd**. Wait for **REPAIR SETTING VERIFIED**, then reopen Illustrator. This enables the unsigned-panel setting described above; it does not reinstall files. |
| The extension is missing from the menu | Check that you use Illustrator **2026 / 30.0–30.9**, that installation showed **Installed**, and that you restarted Illustrator. |
| The installer reports missing files | Extract the entire ZIP again. Run the installer from the extracted folder, not from inside the ZIP. |
| Guides are invisible | Choose **View → Guides → Show Guides** and check that the guide layer is visible. |
| The layout does not fit | Reduce the margins, gutters or column/row count so the layout fits the artboard. |

If installation is blocked by your work computer's policy, ask your administrator. For other problems, contact Ashad with your Illustrator version and the error message.

## Update or uninstall

**Update:** Close Illustrator, extract the newer Windows ZIP and run **Install-Windows.cmd** again. The installer backs up the existing per-user copy before replacing it.

**Uninstall an installer-based copy:** Close Illustrator and run **Uninstall-Windows.cmd**. Type **YES** to remove it. At the next prompt, press **Enter** to keep the unsigned-panel setting, or type **RESTORE** to restore the previous setting. Restoring it may affect other unsigned panels.

For a manually copied installation, follow the removal instructions in the [manual guide](MANUAL-INSTALL.md). The uninstaller does not remove manual copies.
