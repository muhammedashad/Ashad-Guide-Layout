Ashad Guide Layout 3.1.0 — Windows

1. Save your work and close all Illustrator versions.
2. Extract the complete ZIP. Keep all files together.
3. Double-click Install-Windows.cmd.
4. Check the detected versions, read the unsigned-panel notice, type YES.
5. Wait for Installed. Restart Illustrator.
6. Choose Window > Extensions > Ashad Guide Layout.

Targets Illustrator 2019–2026, including 2020 and 2025.
Older versions are compatibility targets, not verified host tests.
Install location: %APPDATA%\Adobe\CEP\extensions\com.ashad.guidelayout
Do not copy into the Illustrator 2026 application folder for multi-version use.

If the panel is missing or blank, close Illustrator and run
Repair-Blank-Panel.cmd LAST, type YES, wait for verification, then restart.
Repair needs the new extension to be installed first.
